# Título [title]

Fuente: https://support.google.com/merchants/answer/6324415

El texto generado por la skill va en `title`, con el aviso de `contenido-ia.md`. Las mismas reglas valen si el usuario pide structured_title.

## Requisitos de Google (incumplir = posible desaprobación)

- De 1 a 150 caracteres.
- Describe con claridad el producto, y tiene que coincidir con el que se ve en la landing.
- Distingue la variante (color, talla, capacidad, sabor…).
- Lenguaje profesional y gramaticalmente correcto.
- Sin idiomas extranjeros salvo términos que se entiendan de forma general.
- Sin mayúsculas para enfatizar (sí para siglas: USB, HD, UK).
- Sin texto promocional: precio, oferta, envío, fechas de entrega, nombre de la empresa como reclamo.
- Sin espacios de más, etiquetas HTML, símbolos ni caracteres llamativos.

## Buenas prácticas de Google

- Usar los 150 caracteres: el título se usa para relacionar el producto con búsquedas.
- Lo importante al principio: según la pantalla se ven unos 70 caracteres.
- Incluir palabras que la gente usa al buscar: tipo de producto, marca, características concretas.
- Marca si es un factor diferencial.
- Casos especiales: lotes ("Cámara + objetivo 18-55 mm y cargador"), packs (cantidad), suscripciones (indicarlo y su duración), productos personalizados (indicarlo), muestras (empezar por "muestra").

## Criterio de la skill

Estructura base: **Tipo de producto + atributo o característica principal + nombre o modelo + marca + variante**.

El orden se adapta a cómo busca la gente en cada vertical. Ejemplos ilustrativos (valores inventados):

| Vertical | Estructura | Ejemplo |
|---|---|---|
| Joyería | Tipo + material + denominación | Anillo de plata de ley con circonitas modelo Aura - Talla 14 |
| Electrónica | Tipo + especificación clave + modelo + marca | Cámara digital retro de 8 MP con 5 filtros vintage - Modelo X - Marca |
| Moda | Marca + tipo + material + color + talla | Marca Camiseta de algodón orgánico para hombre - Azul - M |
| Cosmética | Marca + tipo + beneficio verificable + formato | Marca Sérum facial con ácido hialurónico 30 ml |
| Hogar | Tipo + material + medida + modelo | Lámpara de escritorio LED de aluminio regulable 45 cm - Modelo Lumen |

- Si el usuario aporta informe de términos de búsqueda, prioriza los términos con conversiones y los que faltan en el título actual.
- Los guiones como separador están permitidos; no abuses de ellos ni uses barras verticales o símbolos.
- El título no debe repetirse literalmente en la descripción.
- Evita comillas dobles dentro del texto: si algún día se pasa a structured_title, rompen su formato.
